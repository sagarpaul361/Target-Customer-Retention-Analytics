# 📊 Target Customer Retention Analytics | Power BI

## 📌 Project Overview

This project focuses on analyzing customer retention and understanding customer behavior using Microsoft Power BI. The dashboard helps explore customer trends and identify insights that can support data-driven business decisions.

## 🎯 Project Objectives

- Analyze customer retention patterns.
- Understand customer behavior and trends.
- Identify potential areas for improving customer retention.
- Present key metrics through interactive Power BI dashboards.
- Support business decisions using data visualization.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning and Transformation
- Data Visualization
- Business Intelligence

## 📂 Project Files

- **Project C3 Retention analysis.pbix** — Power BI project file containing the dashboard and analysis.

## 📈 Project Workflow

1. Imported the project dataset into Power BI.
2. Cleaned and transformed the data.
3. Prepared data for analysis.
4. Developed visualizations and dashboard components.
5. Analyzed customer retention trends and business insights.

## 💡 Business Value

The analysis aims to help businesses understand customer retention patterns, evaluate customer behavior, and identify opportunities to improve customer engagement and long-term retention.

## 🚀 How to Use

1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the dashboard and available visualizations.
